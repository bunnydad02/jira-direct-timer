# Jira Local Workspace - Worklog timer v1.17.2

## Changes

- Z panelu je odstranen radek `Zapis do: <KLIC>` pridany ve v1.17.1. Panel
  vypada opet jako drive. Ochrana z v1.17.1 zustava: na strance
  `/browse/<KLIC>` se START a ADD MINUTES vzdy vztahuji k ukolu z adresy
  a `selectedIssue` plati jen na boardu / backlogu.

## Installation / update

Tampermonkey nacita aktualizace z vetve `main`. Vyhledej aktualizace skriptu
a obnov stranku Jiry; panel ma zobrazovat v1.17.2. Neinstaluj druhou kopii
a nemaz data webu, aby zustalo zachovano rozpracovane mereni.

## Verification

Overeno pomoci `npm test`: syntaxe produkcniho skriptu, Node regrese
(vcetne overeni, ze panel nezobrazuje radek s cilem zapisu a ze
`selectedIssue` nepresmeruje zapis), kontroly vydani, bezpecnostni audit
a vsechny Chromium scenare. Testy pouzivaji pouze lokalni mocky, nekontaktuji
Jiru a nevytvareji skutecne worklogy.
