# Jira Local Workspace - Worklog timer v1.17.3

## Changes

- AUTO also observes Jira Server issue and subtask creation forms, including Sub-task Bug; previously it observed only the REST endpoint.
- Form responses use `issueKey`. Without a valid key no work log is sent and the panel shows an error. Form initialization and other origins are not observed.
- Configured minutes, running timers, estimate preservation and duplicate protection remain unchanged. Previously missed entries are not backfilled.

## Installation / update

Tampermonkey loads updates from `main`. After updating to 1.17.3, refresh Jira. Do not install a second copy or clear site data; existing timer state is preserved.

## Verification

`npm test` passed: syntax, Node regressions, release checks, security audit and all Chromium regressions with local mocks. New tests cover 11 minutes (660 seconds), fetch and XMLHttpRequest, invalid responses, other origins, form initialization and recovery from a lost response without retrying a work log. No live Jira is contacted.
