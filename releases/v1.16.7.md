# Jira Local Workspace - Worklog timer v1.16.7

## Changes

- Removed the tooltip listing the last three versions when hovering over or focusing the version; changes remain available on GitHub Releases.
- The version in the panel remains a link to the GitHub repository in a new tab.
- Synchronized the displayed version and update metadata to 1.16.7; a regression checks they match.
- Timer controls, work log saving and unfinished timers are unchanged.

## Installation / update

Tampermonkey loads updates from `main`. After updating to 1.16.7, refresh Jira. Do not install a second copy or clear site data; existing timer state is preserved.

## Verification

Syntax and Node regressions were verified for 1.16.7. Later local Chromium regressions also cover tooltip removal and version display. Tests use simulated Jira, not real work logs.
