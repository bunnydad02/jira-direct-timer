# Jira Local Workspace - Worklog timer v1.17.2

## Changes

- Removed the write-target row added in 1.17.1, restoring the earlier panel appearance. The protection remains: on `/browse/<KEY>`, START and ADD MINUTES target the URL issue, and `selectedIssue` applies only to boards and backlogs.

## Installation / update

Tampermonkey loads updates from `main`. After updating to 1.17.2, refresh Jira. Do not install a second copy or clear site data; existing timer state is preserved.

## Verification

`npm test` passed: production syntax, Node regressions (including absence of the target row and selectedIssue protection), release checks, security audit and all Chromium scenarios. Tests use local mocks only and do not contact Jira or create real work logs.
