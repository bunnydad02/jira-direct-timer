# Jira Local Workspace - Worklog timer v1.17.0

## Changes

- Added optional automatic work logging after issue creation through the Jira page. It is off by default; `auto` beside `ADD MINUTES` opens settings with a default of 10 minutes.
- The work log is added to the new issue, including subtasks, without changing a running timer. Uncertain writes are verified using their marker and never automatically retried.

## Installation / update

Tampermonkey loads updates from `main`. After updating to 1.17.0, refresh Jira. Do not install a second copy or clear site data; existing timer state is preserved.

## Verification

`npm test` passed: production syntax, Node regressions, release checks and all Chromium scenarios. Tests use local mocks only and do not contact Jira or create real work logs.
