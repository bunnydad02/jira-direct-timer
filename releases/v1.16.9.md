# Jira Local Workspace - Worklog timer v1.16.9

## Changes

- The total below the timer now includes only the signed-in user's work logs, not colleagues' entries. Match the Jira author identity, not display name or the user who edited the entry.
- Apply the same filtering to the total including subtasks. Load all pages for the issue and its subtasks instead of Jira aggregate fields that include other users.
- Show identity, author and subtask loading errors instead of an incorrect total. Timing, saving and recovery are unchanged. Hours remain rounded to tenths (15 minutes = 0.3h).

## Installation / update

Tampermonkey loads updates from `main`. After updating to 1.16.9, refresh Jira. Do not install a second copy or clear site data; existing timer state is preserved.

## Verification

`npm test` passed: production syntax, Node regressions, release checks and all Chromium scenarios. Regressions cover personal and colleague time, issue and subtask authors, pagination, matching display names, renamed users, missing identities, loading failures, recovery, navigation and recalculation after saving. Tests use local mocks only and do not contact Jira or create real work logs.
