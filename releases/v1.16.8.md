# Jira Local Workspace - Worklog timer v1.16.8

## Changes

- Show the issue total including subtasks in parentheses after logged time, for example `2h (3.5h)`. Hide it when exact seconds match, including when subtasks have no logged time.
- The total uses Jira aggregate fields without double-counting the parent; the issue total still includes all work log pages. Both values are rounded to tenths of an hour.
- Show aggregate loading errors in the panel. Timing, saving and unfinished timers are unchanged.

## Installation / update

Tampermonkey loads updates from `main`. After updating to 1.16.8, refresh Jira. Do not install a second copy or clear site data; existing timer state is preserved.

## Verification

`npm test` passed: production syntax, Node regressions, release checks and all Chromium scenarios. New tests cover multiple subtasks, pagination, equal and zero times, subtask-only time, refresh after saving and navigation, and aggregate errors. Only local Jira mocks are used; no real work logs are created.
