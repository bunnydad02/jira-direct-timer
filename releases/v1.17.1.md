# Jira Local Workspace - Worklog timer v1.17.1

## Changes

- On `/browse/<KEY>`, START and ADD MINUTES always target the issue in the URL. `selectedIssue` cannot redirect the write; it still works on boards and backlogs (#13).
- When the panel is not tracking the open issue, it shows the write target (#13).
- Marker verification accepts only work logs from the signed-in user. Another author's matching marker no longer blocks automatic or manual entries or confirms an uncertain save (#14).
- Automatic logging observes issue creation only on the Jira page's own origin (#15).

## Installation / update

Tampermonkey loads updates from `main`. After updating to 1.17.1, refresh Jira. Do not install a second copy or clear site data; existing timer state is preserved.

## Verification

`npm test` passed: production syntax, Node regressions (including selectedIssue, marker author and cross-origin creation), release checks and all Chromium scenarios. Tests use local mocks only and do not contact Jira or create real work logs.
