# Jira Local Workspace - Worklog timer v1.17.3

## Changes

- AUTO zachyti take vytvoreni pres Jira Server formulare pro issue a subtasky,
  vcetne Sub-task Bugu. Drive sledovalo pouze REST endpoint, takze vytvoreni
  pres formular nemuselo zapsat nastavene minuty.
- Formularova odpoved se cte z `issueKey`; bez platneho klice se worklog
  neodesle a panel zobrazi chybu. Inicializace formulare a cizi origin se
  nesleduji.
- Nastaveny pocet minut, bezici stopky, zachovani odhadu a ochrana pred
  duplicitami zustavaji zachovany. Drive chybejici vykazy se zpetne nedoplnuji.

## Installation / update

Tampermonkey nacita aktualizace z vetve `main`. Po aktualizaci na 1.17.3
obnov stranku Jiry. Neinstaluj druhou kopii skriptu a nemaz data webu;
stav mereni i nastaveni AUTO zustavaji zachovany.

## Verification

`npm test`: uspesne kontroly syntaxe, Node regrese, kontroly vydani,
bezpecnostni audit a vsechny Chromium regrese s lokalnimi mocky.
Nove testy overuji 11 minut (660 sekund), fetch i XMLHttpRequest,
neplatne odpovedi, cizi origin, inicializaci formulare a obnovu po ztrate
odpovedi bez opakovani worklogu. Testy nekontaktuji skutecnou Jiru.
