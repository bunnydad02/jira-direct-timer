# Jira Local Workspace - Worklog timer v1.17.0

## Changes

- Pridano volitelne automaticke vykazovani po vytvoreni issue pres Jira
  stranku. Funkce je ve vychozim stavu vypnuta; tlacitko `auto` u `ADD MINUTES`
  otevre nastaveni s poctem minut (vychozi hodnota 10).
- Automaticky worklog se prida k nove issue vcetne subtasku bez zmeny
  bezici stopky. Nejisty vysledek zapisu se overuje podle znacky a nikdy se
  automaticky neposila znovu.

## Installation / update

Tampermonkey nacita aktualizace z vetve `main`. Vyhledej aktualizace skriptu
a obnov stranku Jiry; panel ma zobrazovat v1.17.0. Neinstaluj druhou kopii
a nemaz data webu, aby zustalo zachovano rozpracovane mereni.

## Verification

Overeno pomoci `npm test`: syntaxe produkcniho skriptu, Node regrese,
kontroly vydani a vsechny Chromium scenare. Testy pouzivaji pouze lokalni
mocky, nekontaktuji Jiru a nevytvareji skutecne worklogy.
